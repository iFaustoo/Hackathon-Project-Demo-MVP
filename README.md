# Hackathon-Project-Demo-MVP
Project Memory Engine (Memoria Operativa Inteligente): Un agente autónomo que escucha las comunicaciones informales de los equipos (chats, correos, o fotos de pizarra) y mantiene viva y actualizada la bitácora de cada proyecto sin intervención humana, con un único fin de automatizar y facilitar el acceso a información y la organización de la misma.
